# Подключение новой клиники — регламент для ZMed

Внутренний документ. Описывает, что делает менеджер / админ ZMed, когда
клиника подтвердила желание работать в системе.

---

## Чек-лист подключения

Все шаги — в Flask-админке `https://<домен>:5102` (кто-то из супер-юзеров,
например `admin` или `molchanova`).

### 1. Создать организацию-клинику

1. В шапке → **«🏥 Организации»**.
2. Кнопка **«+ Новая»**.
3. Заполнить:
   - **Имя** — официальное название клиники (как в договоре). Будет
     отображаться в списках ZMed.
   - **ИНН** — опционально, для сверки с `inn_lpu`.
   - **Вид** — `clinic`.
   - **Активна** — да.
4. Сохранить.

### 2. Создать пользователя клиники

1. Шапка → **«Пользователи»** → **«+ Новый»**.
2. Заполнить:
   - **Логин** — короткий, без пробелов. Пример: `clinic-moskva-01`.
   - **Пароль** — сгенерировать 10-12 символов. Записать **один раз** в
     защищённом месте, чтобы отправить клинике (потом в системе он хранится
     только хешем).
   - **ФИО** — реальное ФИО сотрудника клиники (НЕ юридического лица).
   - **Email** — рабочий. Понадобится для OTP-подписи отчётов и копии
     писем о заказах.
   - **Telegram ID** — опционально. Если заполнен, клиника сможет получать
     TG-напоминания про молчание (`clinic_silence_check`).
   - **Организация** — созданная на шаге 1.
   - **Модули** — поставить галки:
     - ☑ `clinic_reports`
     - ☑ `clinic_stock`
   - **Активен** — да.
   - **Суперпользователь** — **нет** (клиника не должна видеть админку).
3. Сохранить.

### 3. Проверить вход

До отправки доступов — зайди под созданной учёткой сам:

1. В инкогнито открой `https://<домен-PWA>` → логин/пароль из шага 2.
2. На главной должны быть видны плитки «📋 Отчёты клиник» и «📦 Учёт ОХ».
   Других плиток быть не должно (клиника не видит импланты/расходники/ИНН).
3. Перейди в «Отчёты клиник» — список пуст.
4. Перейди в «Учёт ОХ» — пусто, предложение создать первую локацию.
5. Разлогинься.

### 4. Отправить клинике письмо-приглашение

Шаблон (пример, адаптируй под корпоративный стиль):

```
Добрый день!

Для ведения отчётности по операциям с имплантами ZMed и учёта движения
товара на ОХ мы подключили вас к системе ZMed PWA.

Ссылка для входа: https://<домен-PWA>
Логин: <логин из шага 2>
Пароль: <пароль из шага 2>

Пароль рекомендуем сменить при первом входе (кнопка «Профиль»).

Инструкции во вложении:
  • Отчёты об операциях — CLINIC_GUIDE_REPORTS.pdf
  • Учёт имплантов на ОХ — CLINIC_GUIDE_STOCK.pdf

Технические вопросы — <email менеджера ZMed>.

С уважением,
<менеджер ZMed>
```

### 5. Зафиксировать подключение внутри ZMed

- Сообщить об успешном подключении Аркадию и команде.
- Записать в CRM / внутреннем трекере: клиника, логин, ответственный
  менеджер, дата подключения.

---

## Если клинику нужно отключить

- Админка «Пользователи» → найти юзеров клиники → снять галку **«Активен»**.
  Данные остаются в БД, но войти невозможно.
- Админка «Организации» → найти клинику → снять **«Активна»**. Клиника
  пропадёт из фильтров, её отчёты останутся в архиве для сверки.

Данные **не удаляем** — они нужны для аудита и возможной сверки с 1С.

---

## Если клинике нужен ещё один сотрудник

Повторить шаг 2 для нового юзера, привязав к той же организации. Все юзеры
одной клиники видят все её отчёты (это нужно для подмены / выхода сотрудника
в отпуск).

---

## Если сотрудник забыл пароль

Админка → «Пользователи» → его строка → «Редактировать» → поле «Новый пароль»
→ сохранить. Сообщить клинике новый пароль.

---

## Что менеджеру ZMed делать периодически

- Раз в неделю — зайти в «📋 Отчёты клиник», посмотреть новые submitted-ы,
  проставить тег «Требует разбора» на спорные.
- Раз в месяц — сверить «Потери» по каждой клинике (XLSX-экспорт на странице
  «Потери»). Расхождения — согласовать с клиникой.
- Еженедельно в понедельник проверить email «Молчат N клиник». Если молчащая
  клиника в списке — созвониться.
